# ReadSphere 📚

ReadSphere is a Digital Library Management System built with React. It provides a responsive interface for browsing books, viewing book details, searching and filtering the collection, sorting books, managing books through CRUD operations, and simulating book borrowing and returning.

## Objective

The project demonstrates:

- React development
- React Router navigation
- Reusable components
- State management
- CRUD operations
- API integration
- Form validation
- Responsive web design

## Features

- 🏠 Landing/Home page
- 📚 Browse Books
- 🔎 Search books by title or author
- 🏷️ Filter books by genre/category
- ↕️ Sort books by title and publication year
- 📖 Featured Books
- 🔗 Book Details pages
- 🔄 Borrow/Return simulation
- 📋 Borrowed Books page
- 🗂️ Categories page
- ➕ Book CRUD management
- 🔐 Login page
- 📝 Signup page
- 🔑 Forgot Password page
- 📱 Responsive design for desktop, tablet and mobile
- 🧭 React Router navigation
- 🧩 Reusable React components
- ⏳ Loading state for API requests
- 🌐 Open Library API integration

## Required Pages

The application includes the following required pages:

### Landing Page

The home page introduces ReadSphere and displays featured library content.

### Browse Books

Users can:

- Search for books
- Search by title or author
- Filter books by genre
- Sort books by title
- Sort books by publication year
- Borrow available books
- Return borrowed books
- View book details

### Book Details

Users can view detailed information about a selected book, including:

- Title
- Author
- Genre
- Publication year
- Availability status
